# SERVICES — Flutter starter

## Запуск
1. Установите Flutter SDK.
2. Выполните `flutter pub get`.
3. Выполните `flutter run`.

## Архитектура
- `features/`: экраны по функциональным областям.
- `data/models.dart`: доменная модель и демо-данные.
- `shared/app_shell.dart`: нижняя навигация.
- `app.dart`: маршрутизация GoRouter и тема.
